# React Flow 能力地图原型

这是独立的探索原型：免费 React Flow 库，自行设计深色冷青界面，没有复制或购买官方付费 Workflow Editor 模板。

从用途分类进入技能卡片；详情按需显示 description、当前来源、原文、关系与证据。搜索是字面检索；分类是编辑器标注；连接不表示执行流程。关系标签是独立按钮，可准确打开对应证据。

## 构建

在当前目录执行（先遵守当前用户的计算执行授权）：

```sh
npm ci
npm run build
```

仅输出并清理 `../../web/flow-lab/`，不清理整个 web。通过仓库根的本地 Python 服务访问 `/flow-lab/index.html`。使用同源 API，不放宽 Host/Origin。

第一次使用先到主编辑器显式扫描自己的目录，再回体验页重读。这个页面只 GET `/api/inventory` 与 `/api/skill`，不会发现新增文件或自动安装 skill；没有写入或模型调用。

默认显示个人用途概览，未知项归入待整理。来源与历史会话口径分开说明。只有所选、同一视图内、当前引文匹配的非普通引用关系画线。没有作者审阅数据时不会伪造关系。

布局只存浏览器坐标。Codex 按钮生成提示，需要用户复制到对话；没有订阅桥接或自动发消息。当前仍是原型，后续是否成为主界面需单独决定。发布验证范围见根目录 docs/VALIDATION.md。
